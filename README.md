# 💻 LaptopGuard – Premium Laptop Store

**LaptopGuard** is a premium laptop shopping website designed to help customers explore and discover laptops from popular technology brands. It provides a modern shopping interface with a professional black-and-gold theme.

## 🌟 About the Project

LaptopGuard is an online laptop-selling platform where customers can explore different laptop brands, browse laptop collections, view product information and discover laptops according to their needs.

The website aims to provide a simple, attractive and user-friendly laptop shopping experience.

## ✨ Features

- Premium homepage design.
- Laptop product showcase.
- Multiple laptop brands.
- Brand-wise laptop browsing.
- Gaming, Business and Student laptop collections.
- Laptop product images.
- Product information and specifications.
- Search and browsing interface.
- Wishlist interface.
- Shopping cart interface.
- About Us page.
- Contact Us page.
- Responsive website design.

## 🛠️ Technologies Used

- **HTML5** – Website structure.
- **CSS3** – Styling and layout.

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the LaptopGuard project folder.
3. Locate the `index.html` file.
4. Double-click `index.html`.
5. The website will open in your browser.

No additional installation is required to open the website locally.
